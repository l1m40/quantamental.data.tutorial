# Quantamental Data Lake Tutorial

> 📖 **Documentação online:** https://l1m40.github.io/quantamental.data.tutorial/

Bem-vindo ao **Quantamental Data Lake Tutorial**.

Este repositório reúne tutoriais, exemplos e documentação sobre a utilização do **Quantamental Data Lake**, apresentando os principais conceitos utilizados na construção de modelos quantitativos para análise de empresas e ativos financeiros.

O objetivo é oferecer um material introdutório para analistas, pesquisadores e desenvolvedores que desejam compreender como os dados do Data Lake são organizados e utilizados em modelos Quantamentais.

---

## O que você encontrará

O tutorial foi desenvolvido para apresentar os conceitos de forma progressiva, permitindo que o leitor evolua desde a organização dos dados até a construção de indicadores quantitativos.

Os principais tópicos incluem:

- Ontologia do universo de ativos
- Similaridade entre empresas
- Similaridade entre setores
- Features
- Famílias de variáveis
- Valuation
- Qualidade
- Crescimento
- Momentum
- Risco
- Liquidez
- Distribuição de Features
- Normalização
- Feature Engineering
- Quantamental Scores

Novos capítulos serão adicionados continuamente.

## Público-alvo

Este material destina-se a:

- Analistas Quantitativos
- Analistas Fundamentalistas
- Cientistas de Dados
- Pesquisadores
- Estudantes
- Desenvolvedores que utilizam o Quantamental Data Lake

Não é necessário possuir experiência prévia em modelos Quantamentais. Os conceitos são apresentados de maneira gradual e ilustrados com exemplos práticos.

## Objetivos

Ao final da leitura, espera-se que o usuário seja capaz de:

- compreender a organização do Quantamental Data Lake;
- navegar pela ontologia de empresas e setores;
- entender o conceito de features;
- identificar as principais famílias de variáveis;
- interpretar indicadores quantitativos;
- utilizar os dados do Data Lake em análises próprias;
- compreender os fundamentos da abordagem Quantamental.
